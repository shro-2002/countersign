# Held-out evaluation cases

**Status: not yet written. Nothing has been tuned against them.**

## Rules

- The cases must be written by a model from a **different vendor** than the one used during development, or by a person who has not seen the Countersign policy code.
- Before any results are run, commit the cases with their SHA-256 hash recorded in this file.
- Run them only once, after the policy code is frozen for submission.
- Report the results separately from the frozen set (`../frozen/refund_cases.json`).
- No fixes may be made in response to held-out results before they are reported.
